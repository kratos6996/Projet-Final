# Ny Asa-tanako

Site vitrine professionnel pour **Ny Asa-tanako**, marque de consultance et formation en Responsabilité Sociétale des Entreprises (RSE) à Madagascar.

## Contexte

Site cohérent avec le positionnement de MIASAdvisory (entreprise familiale, Antananarivo, RSE B2B uniquement, interventions à la commande), présenté sous le nom de marque **Ny Asa-tanako** (« l’œuvre de mes / nos mains » en malgache).

## Contenu

- Accueil / Hero avec promesse de marque
- À propos (entreprise familiale, modèle opérationnel)
- Services : Consultance RSE + Formations RSE
- Méthode en 4 temps
- Zones d’intervention (Antananarivo, Fianarantsoa, Toamasina → ambition nationale)
- Formulaire de contact
- Footer

## Design

- **Palette camel** (conforme au brief) :
  - Camel principal : `#C19A6B`
  - Brun profond : `#8A6B4F`
  - Beige clair : `#F4E8D6`
- Logo textuel : monogramme **NA** (2 lettres max)
- Typographie : Cormorant Garamond (titres) + Source Sans 3 (corps)
- Responsive (mobile, tablette, desktop)

## Utilisation

Ouvrir simplement `index.html` dans un navigateur, ou servir le dossier avec un serveur local :

```bash
# Exemple avec Python
python3 -m http.server 8080
# puis ouvrir http://localhost:8080
```
